Plan de Estudio y Proyecto (12 semanas)
Semana 1 – Fundamentos y entorno de trabajo
Objetivo: Entender qué hace un analista de datos y preparar tu entorno.

Actividades:

Introducción al rol de Data Analyst (responsabilidades, flujo de trabajo).

Instalación de herramientas: Python, Jupyter Notebook, VS Code, Excel, Power BI.

Proyecto: Definir el caso de estudio → Empresa ficticia de ventas minoristas (dataset de ventas, clientes y productos).

Entrega: Documento con descripción del proyecto y setup listo.

Semana 2 – Excel avanzado para análisis
Objetivo: Dominar funciones clave de Excel.

Actividades:

Tablas dinámicas, funciones de búsqueda (VLOOKUP, INDEX-MATCH).

Limpieza básica de datos en Excel.

Proyecto: Primer análisis exploratorio de ventas en Excel.

Entrega: Dashboard inicial en Excel con KPIs básicos (ventas totales, clientes activos).

Semana 3 – Fundamentos de estadística aplicada
Objetivo: Comprender estadística descriptiva y probabilidad.

Actividades:

Media, mediana, desviación estándar, percentiles.

Distribuciones y visualización de datos.

Proyecto: Reporte estadístico de ventas y clientes.

Entrega: Informe con gráficos y métricas descriptivas.

Semana 4 – SQL básico
Objetivo: Aprender a consultar bases de datos.

Actividades:

SELECT, WHERE, JOIN, GROUP BY.

Proyecto: Crear consultas para responder preguntas de negocio (ej. “¿Cuál es el producto más vendido?”).

Entrega: Script SQL con consultas clave.

Semana 5 – Python para análisis de datos (I)
Objetivo: Introducción a Python y librerías.

Actividades:

Numpy y Pandas: manejo de DataFrames.

Proyecto: Importar dataset de ventas y hacer limpieza en Python.

Entrega: Notebook con dataset limpio y listo para análisis.

Semana 6 – Python para análisis de datos (II)
Objetivo: Análisis exploratorio con Python.

Actividades:

Agrupaciones, filtrado, KPIs en Pandas.

Proyecto: Generar métricas de negocio (ventas por región, clientes nuevos).

Entrega: Notebook con análisis exploratorio.

Semana 7 – Visualización de datos
Objetivo: Aprender a comunicar hallazgos.

Actividades:

Matplotlib y Seaborn.

Proyecto: Gráficos de tendencias y comparaciones.

Entrega: Notebook con visualizaciones claras y explicadas.

Semana 8 – Power BI (I)
Objetivo: Construcción de dashboards interactivos.

Actividades:

Conexión a Excel/CSV.

Creación de medidas y visualizaciones.

Proyecto: Dashboard de ventas en Power BI.

Entrega: Dashboard con filtros y KPIs.

Semana 9 – Power BI (II)
Objetivo: Modelado de datos y DAX.

Actividades:

Relaciones entre tablas.

Medidas avanzadas con DAX.

Proyecto: Dashboard con métricas personalizadas.

Entrega: Dashboard final con storytelling.

Semana 10 – Proyecto integrador (I)
Objetivo: Unir todo lo aprendido.

Actividades:

Definir preguntas de negocio (ej. “¿Qué región tiene mayor crecimiento?”).

Integrar SQL, Python y Power BI.

Entrega: Plan del proyecto con objetivos claros.

Semana 11 – Proyecto integrador (II)
Objetivo: Construcción del informe final.

Actividades:

Análisis completo en Python.

Visualizaciones en Power BI.

Informe ejecutivo en PowerPoint.

Entrega: Informe preliminar.

Semana 12 – Presentación final
Objetivo: Simular entrega profesional.

Actividades:

Preparar presentación ejecutiva.

Explicar hallazgos y recomendaciones.

Entrega: Dashboard + informe + presentación.
